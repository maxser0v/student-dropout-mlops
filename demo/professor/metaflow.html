Metaflow pipeline

This walkthrough follows the recorded rehearsal 1795422454480757. The rehearsal used synthetic reports, real XGBoost training, and a stand-in for the MiniLM encoder.

  1. start loads configuration and opens the experiment run.
  2. validate checks the inputs and training and validation splits.
  3. prepare retrieves candidate passages and generates similarity features. The full pipeline uses frozen MiniLM here.
  4. train fits the XGBoost classifier using reviewed examples.
  5. log_model logs and reloads the candidate to verify its predictions.
  6. evaluate selects a review threshold on the validation set and measures recall and false alerts.
  7. gate applies the release criteria to the validation results.
  8. register registers a candidate when it qualifies.
  9. end records the decision and run identifiers.
